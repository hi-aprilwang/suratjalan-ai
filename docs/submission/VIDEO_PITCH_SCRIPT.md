## 3. VIDEO 2: Video Proof of Work / PoW (Maksimal 7 Menit — Unlisted YouTube)

### Protokol Strict No-Cut dan Panduan Rekaman

> [!CAUTION]
> **ATURAN WAJIB COMPFEST 18 AIC UNTUK VIDEO PROOF OF WORK**:  
> 1. **DILARANG MELAKUKAN EDIT CUT / POTONGAN VIDEO** selama sesi demonstrasi teknis berlangsung.  
> 2. Diperbolehkan melakukan **Fast-Forward (percepatan video)** pada proses instalasi panjang dan menambahkan narasi / voiceover.  
> 3. **JAM SISTEM REAL-TIME (Windows Taskbar Clock / Widget Digital) WAJIB TERLIHAT JELAS DI LAYAR** sepanjang video untuk membuktikan rekaman berjalan kontinyu tanpa manipulasi.

### Skenario Eksekusi PoW Langkah-demi-Langkah (Continuous Uncut Sequence):

1. **00:00 – 01:15 (Cloning & Docker Startup)**:
   - Tunjukkan desktop dengan jam Windows di taskbar yang terus berdetik.
   - Buka PowerShell / Terminal: `git clone https://github.com/hi-aprilwang/suratjalan-ai.git`.
   - Jalankan perintah: `docker compose up --build`.
   - *(Dapat di-fast-forward selama proses build layer container)*.
   - Tunjukkan backend status `Up (healthy)` pada port `8000` dan frontend pada port `3000`.

2. **01:15 – 02:00 (Verifikasi Endpoint & Buka Browser)**:
   - Buka Google Chrome di sebelah kanan terminal.
   - Akses `http://localhost:8000/api/health` -> Tunjukkan respon JSON `{"status":"healthy"}`.
   - Buka `http://localhost:3000` -> Tunjukkan UI Workstation SuratJalan.AI termuat sempurna.
   - Buka tab `http://localhost:3000/how-it-works` -> Tunjukkan penjelasan alur kerja dan skema perbandingan.

3. **02:00 – 03:00 (Uji Preset 1: PT Indofood Clean Approval)**:
   - Kembali ke dashboard utama `http://localhost:3000`.
   - Klik tombol **Preset 1 (Indofood)** atau tekan shortcut keyboard <kbd>1</kbd>.
   - Perhatikan terminal di sebelah kiri menampilkan log inferensi backend.
   - Layar browser menampilkan animasi laser scanner dan hasil audit 165 karton 100% matched.

4. **03:00 – 04:15 (Uji Preset 2: PT Mayora Retur & Spatial Grounding)**:
   - Klik **Preset 2 (Mayora)** atau tekan shortcut <kbd>2</kbd>.
   - Arahkan kursor mouse (hover) ke baris Beng Beng di tabel rekonsiliasi.
   - Tunjukkan kotak bounding box merah di sisi kiri menyala tepat di atas tulisan tangan *"RETUR 8 DUS BASAH"*.
   - Tunjukkan kalkulasi potongan klaim otomatis senilai Rp1.440.000.

5. **04:15 – 05:15 (Uji Preset 3: Wings Group Missing Stamp Security Alert)**:
   - Klik **Preset 3 (Wings Group)** atau tekan shortcut <kbd>3</kbd>.
   - Tunjukkan peringatan **CRITICAL_REJECTED** dan pesan *"SECURITY ALERT: MISSING STORE STAMP"*.
   - Jelaskan bahwa sistem mencegah kebocoran finansial dari dokumen tanpa legalitas sah.

6. **05:15 – 06:15 (Uji Skenario Tambahan & Upload Custom File)**:
   - Klik **Preset 4** (Cold chain Frisian Flag), **Preset 5** (Semen Indonesia), dan **Preset 6** (Kalbe Farma).
   - Tunjukkan tombol *"Unggah Foto Surat Jalan Lain"* dan drag & drop file contoh dari folder `samples/`.

7. **06:15 – 07:00 (Uji Modal Sinkronisasi ERP & Penutup PoW)**:
   - Klik tombol **"Sinkronisasi ERP / Export JSON"**.
   - Buka tab **SAP S/4HANA**, **Odoo ERP**, dan **Jurnal.id**.
   - Tunjukkan tombol *"Download Payload JSON"* dan klik untuk mengunduh file JSON hasil ekspor.
   - Tunjukkan log terminal bersih tanpa error.
   - Berikan pernyataan penutup singkat ke arah jam sistem untuk mengonfirmasi rekaman utuh selesai.

## 4. Checklist Aset dan Rekaman Layar

Sebelum memulai proses rekaman, pastikan daftar periksa berikut telah siap:

- [ ] **Resolusi Layar**: Set display ke **1920x1080 (Full HD, 60fps)**.
- [ ] **Browser Zoom**: Set Google Chrome ke **100%** atau **110%** agar teks dan tabel terbaca tajam.
- [ ] **Konektivitas**: Docker Desktop aktif, port 3000 & 8000 tidak terblokir.
- [ ] **Jam Sistem (Khusus PoW)**: Pastikan jam Windows taskbar di pojok kanan bawah menampilkan detik (*Seconds*) atau gunakan widget digital clock di layar.
- [ ] **Mikrofon & Audio**: Rekam audio voiceover di ruangan yang tenang dengan noise cancellation aktif.
- [ ] **Theme Showcase**: Siapkan demonstrasi peralihan tema Light Mode dan Dark Mode melalui tombol switch di Navbar.
- [ ] **Ekspor Video**: Render video final dalam format **MP4 (H.264/AAC, Bitrate 12-16 Mbps)** untuk kualitas visual maksimal di YouTube.
